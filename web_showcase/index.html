“Your thoughts and company workshops belong on your hardware, not a remote server queue.”
Modern transcription tools require continuous internet, cloud accounts, and monthly API subscriptions that transmit sensitive discussions outside your perimeter.

WorkshopFlow reimagines note-taking from the ground up: your audio stays in local app directories, your notes live in an encrypted SQLite database, and summaries run locally through your own GPU with LM Studio.

Engineered for deep work

Designed with the tactile clarity of print and the power of edge machine learning.

⚡

Dual Platform Native

Compiled natively for Windows 11 desktop with high-performance MediaFoundation audio and Android mobile with responsive Material 3 layouts.

🧠

Qwen & LM Studio

Integrates with OpenAI-compatible local APIs. Overlapping chunking processes 2-hour long sessions without truncating nuances or hitting memory ceilings.

💾

Drift SQLite Engine

Write-Ahead Logging (WAL) and foreign-key cascades ensure transactional safety. Fast full-text search across titles, topics, tags, and transcripts.

Private Infrastructure

Works with your laptop's local LLM

Fire up LM Studio, load your favorite model (Qwen 2.5 7B, Mistral, or Llama 3), and start the local server on port 1234. WorkshopFlow auto-detects the host on Windows and routes LAN IP traffic for Android.
